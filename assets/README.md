# Brand assets

The AppleRPC logo is an original design: a music note whose stem broadcasts a signal. It is not derived from the
Apple Music or Discord logos. Licensed under the same terms as the project (AGPL-3.0).

| File | Use |
|---|---|
| `logo.svg` | Master artwork (vector). |
| `logo-512.png` | Discord Developer Portal → **General Information → App Icon**. |
| `logo-1024.png` | Discord Developer Portal → **Rich Presence → Art Assets**, key `applerpc` (fallback image). |
| `AppleRPC.ico` | Tray / executable icon (16–256 px). Sizes up to 48 px use `logo-small.svg`. |
| `logo-small.svg` | Chunkier variant (thicker strokes, two waves) that stays legible at tray-icon sizes. |
